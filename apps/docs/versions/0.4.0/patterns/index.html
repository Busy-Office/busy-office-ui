Patterns

Not a component reference — for one control's API, use the component docs instead. This is every full ERP screen this framework documents, grouped the way a working day actually runs: find something, work one record, correct data, clear a queue, monitor what ran. Every tile's text is generated from its pattern page's own opener, complexity badge and Components-used list, so it cannot drift from the page it describes. Tiles whose screens read at this size also carry a live miniature — a small, inert composition of the same shipped CSS, not an image — while dense screens stay text-only on purpose: a list-report shrunk to a tile is grey noise. Within each group, tiles order simplest first.
