Built from the back office out

Density is a dimension

One attribute — data-density — remaps a token tier: 30 / 40 / 48px rows, cascading, overridable per region. Users pick; text never clips.

The cascade is the API

All framework CSS lives in @layer; your unlayered CSS always wins. Re-brand by remapping tokens — live:

/* brand.css — unlayered, so it wins. An accent swap is a FAMILY swap: */
:root {
  --bo-color-accent-solid: #0f766e;   /* your teal, >= 4.5:1 under white */
  --bo-color-accent-strong: #115e59;
  --bo-color-focus-ring: #0d9488;     /* else focus stays blue */
  --bo-color-bg-selected: #f0fdfa;    /* else selected rows stay blue */
  --bo-font-sans: "Your Corporate Sans", system-ui, sans-serif;
}
/* full recipe incl. the dark-mode rule -> Theming guide */

Pilot one screen

No framework earns 200 screens on a landing page. Take one screen — à la carte, into your existing app:

import "@busy-office/ui/css/tokens.min";
import "@busy-office/ui/css/reset.min";
import "@busy-office/ui/css/components/data-table.min";
/* one screen, ~3.8 kB gzipped — the exact files above.
   Your unlayered CSS already outranks all of it. */

What you're not signing up for: semantic tokens, documented class names, and data-*/ARIA contracts are the versioned API; the cascade contract means leaving is incremental overrides, not a rewrite. The exit is cheap by design — verify it, don't trust it.

Reviewed like it matters

Every slice went through an adversarial multi-seat design review before sign-off: 39 components, three review rounds, every gate finding fixed or on the public ledger. Two rules that came out of it are now build-enforced: every container query is named, and every state signal carries a non-color cue plus a programmatic channel. The full trail — findings, NO-GO verdicts, and the fixes that answered them — is public in the repo.
