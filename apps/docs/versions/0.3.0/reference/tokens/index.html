Token reference

Look-up tables for every shipped token, generated from the CSS on each build: resolved values per theme, spacing, density aliases, and the CI-gated contrast ratios. For what the tiers MEAN and when to reach for which, read Design tokens once — this page is the reference you come back to. The semantic tier is stable API: renaming or removing any token below is a major version (versioning). Each token resolves per theme to a scale step (or a deliberate literal); status colors carry meaning and are never re-skinned by palettes.

Density aliases

Components never hard-code sizes — they read six aliases (--bo-density-control-height, --bo-density-row-height, --bo-density-cell-padding-y, --bo-density-cell-padding-x, --bo-density-field-gap, --bo-density-font-size) that remap when data-density changes. Try it: the Density picker in this page's header re-sizes the control below.
