Tabs

ARIA tabs pattern: CSS styles aria-selected, panels hide via the hidden attribute, initTabs() adds roving tabindex and arrow-key navigation with automatic activation.

Markup

<div class="bo-tabs">
  <div class="bo-tabs__list" role="tablist" aria-label="Purchase order">
    <button class="bo-tabs__tab" role="tab" id="t-details"
            aria-selected="true" aria-controls="p-details">Details</button>
    <button class="bo-tabs__tab" role="tab" id="t-lines" tabindex="-1"
            aria-selected="false" aria-controls="p-lines">Lines</button>
  </div>
  <div class="bo-tabs__panel" role="tabpanel" id="p-details"
       aria-labelledby="t-details" tabindex="0">…</div>
  <div class="bo-tabs__panel" role="tabpanel" id="p-lines"
       aria-labelledby="t-lines" tabindex="0" hidden>…</div>
</div>
<script type="module">
  import { initTabs } from "@busy-office/ui/js";
  initTabs(); // once — arrow keys, Home/End, roving tabindex
</script>

Tabs require initTabs() — there is no CSS-only fallback. Without it the pre-set tabindex="-1" leaves tabs 2+ keyboard-unreachable. Arrow keys are direction-aware in RTL.

JS required REQUIRED: initTabs() — without it tabs 2+ are keyboard-unreachable and inert; there is no CSS-only fallback.
  • ARIA contract: role=tablist/tab/tabpanel, aria-controls/aria-labelledby, panels hidden via the hidden attribute; add role="list" where lists are styled.
  • Arrow keys are RTL-aware; activation is automatic on focus move.
