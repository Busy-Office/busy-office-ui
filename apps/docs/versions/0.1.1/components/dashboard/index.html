Dashboard

Widgets are named containers: a table inside a half-width widget auto-compacts while the same table full-width does not. Stat values use proportional figures (tabular-nums is reserved for columns); compact big values server-side (12.9K, $4.2M). One hero figure per view, maximum. Looking for a "Card"? .bo-widget is it — header/body/band composition, independent of dashboards; see "Widget parts" below.

The hero tile spans two columns (.bo-widget--span-2) and collapses to one when the grid (a named container) drops below its two-column width. One hero per view, max.

Widget parts — header, body, band

.bo-widget is the framework's card primitive — filed under "Dashboard" because that's its most common use, but it composes into any card-shaped UI: a widget is __header / __body / __band. The band footer carries a status message (--msg) or actions — one durable strip. This is what record and approval cards are built from.

Collapsible opt-in

data-collapse-trigger + initCollapsibleCards(): the trigger's aria-expanded and the panel's data-state are the two-channel contract (chevron rotation is decoration on top). CSS does the height transition — same grid-template-rows 0fr/1fr technique as the Motion module's .bo-motion-collapse. No data-state at all defaults to open, so this degrades to a plain always-open widget without the behavior wired up.

Shipping details

123 Warehouse Rd, Dock 4 · Carrier: Freightline · ETA 14 Aug

<div class="bo-widget">
  <header class="bo-widget__header">
    <span class="bo-widget__title">Shipping details</span>
    <button class="bo-btn bo-btn--ghost bo-btn--icon" data-collapse-trigger
            aria-expanded="true" aria-controls="ship-body" aria-label="Toggle">
      <span class="bo-widget__toggle-icon">▾</span>
    </button>
  </header>
  <div class="bo-widget__collapse" id="ship-body" data-state="open">
    <div class="bo-widget__body">123 Warehouse Rd, Dock 4</div>
  </div>
</div>
<script type="module">
  import { initCollapsibleCards } from "@busy-office/ui/js";
  initCollapsibleCards(); // once, ever — event delegation
</script>

Markup

<div class="bo-widget">
  <div class="bo-stat">
    <span class="bo-stat__label">Open invoices</span>
    <span class="bo-stat__value">1,284</span>
    <span class="bo-stat__delta bo-stat__delta--bad">
      <span aria-hidden="true">▲</span> +12%
      <span aria-hidden="true">⚠</span>
      <span class="bo-visually-hidden">increase, worse,</span> vs July
    </span>
  </div>
</div>
<!-- Valence has two channels: the visible ⚠ on BAD deltas (arrow + sign only
     carry direction — a colorblind reader can't tell good ▲ from bad ▲) and
     the visually-hidden text for screen readers. Glyphs are aria-hidden so
     AT hears "+12%, increase, worse, vs July" without triangle noise. -->
