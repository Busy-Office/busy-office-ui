## A — the self-test that stopped running the moment its gate stopped having work

**312.2 removed `paths-ignore` from `ci.yml` entirely.** `check-ci-ignores.mjs`
correctly no-ops in that state: it prints *"declares no paths-ignore, so no path
is exempt … and there is nothing to verify"* and `process.exit(0)`s. That early
return sits at **line 219**. The `--self-test` branch sat at **line 293**.

So from `312.2` onward, `node check-ci-ignores.mjs --self-test` ran **zero of its
18 cases** and exited 0.

**Red-proved, injection confirmed present before each run** (CLAUDE.md: a green
red-proof is a defect in the injection until proven otherwise — and the first
attempt here *was* one: a `grep -c` control with nested quotes returned 0, so
that run was discarded and re-done with a `ZZINJECTED` marker and `grep -c -F`):

| tree state | injected wrong case | `--self-test` |
|---|---|---|
| `ci.yml` as shipped (no `paths-ignore`) | yes | **rc=0**, 0 cases — the defect |
| `paths-ignore:` restored with a control entry | yes | rc=1, 18 cases |
| `paths-ignore:` restored, injection removed | no | rc=0, 18 cases |

The injection was one fixture's expectation flipped from `true` to `false` on a
case whose truth is `true`, renamed `ZZINJECTED` so the control greps the exact
line it changed. The control entry used to restore `paths-ignore` was
`visual-baselines/**` — in `SOURCE_SKIP_DIRS`, so it cannot itself fail — which
is the same control Slice 313 chose.

**`check:selftests` reports this gate as self-tested and is not lying by its own
contract — which is the finding.** The meta-gate asserts
`/process\.argv\.includes\(['"]--self-test['"]\)/` against the source: the branch
**exists**. It never executes it. Its own header records fixing exactly one step
of this: *"The first version matched the string `--self-test` and every heuristic
gate passed — because the tag text itself says 'Carries --self-test' … It now
requires the argv branch that actually runs one."* **Mention → implementation was
closed; implementation → reachable was not.** CLAUDE.md's own line on this gate
— *"Assume this failure mode applies to your check too, including the check you
are writing to catch it"* — landing a third time.

The claim it publishes today: `self-test check passed — 54 gates classified: 20
heuristic (all self-tested), 34 exact`. **19 of those 20 are self-tested.**

### The base rate, and the two wrong readings it took to get it

Per 94.11 the predicate has to discriminate, so every `@heuristic` gate was run
with `--self-test` and its output read. **The first two readings were both wrong,
in the two ways this repo already writes down:**

1. **8 of 20 ran zero cases** — taken with **no `apps/docs/dist`**. Four of the
   eight (`components-used`, `forced-colors`, `page-shape`, `markup`) were dying
   on the missing build before reaching their own branch. *An instrument's first
   output is not evidence.*
2. **4 of 20 ran zero cases** — taken after building, but counted with
   `grep -c '^self-test: '`, which is the shared `selfTest()` helper's format.
   `check-resume-charter` (9 cases, `ok  <name>`), `check-resume-slice-ids` (12
   cases, same), and `check-rf-floor` (its own single-line verdict) all run their
   cases in **bespoke** formats. *A context/format regex is secretly a filter.*

**The honest number is 1 of 20 (5%).** It discriminates, and it is small — which
is the argument against reaching for a new gate here (below).

### What the defect actually costs, said at its real size

The gate's *plain* run is correctly a no-op today, so **nothing is currently
mis-verified**. The loss is latent and precisely-placed: the gate exists as a
tripwire for the day someone re-adds a `paths-ignore` entry, and its
proof-of-competence was disabled at the same moment its work was. The tripwire
and its calibration went dark together.

Worth stating alongside it: with no `paths-ignore`, **all three of this gate's
`assertScanned` reconciliations (lines 233, 291, 420) are also below the early
return**, so `check:ci-ignores` — which runs in CI, inside `check:repo` — asserts
nothing at all today. That is correct behaviour, not a second defect; it is the
reason the self-test is the only thing keeping the gate honest.

**A second unreachability route was found while fixing the first**: the
docs-image SKIP path (`ci.yml` legitimately absent from that build context, line
187-193) also returned before the self-test. The fix clears both, and both are
red-proved above.

### The fix, and why it is a move rather than a rewrite

All five detector helpers (`opensPath`, `namesPathRoot`, `enumeratesRepo`,
`keptExtensions`, `readsFile`) are `function` **declarations** at lines 94-165 —
above the `ci.yml` read — so the block moves up with no reordering of anything
else. The fixtures need neither `ci.yml` nor a build context, so running them
earlier costs nothing.

`@media print`" — three `#ffffff` inside `light-dark()`. Base rate first: the

**None returns 139**, and the tree has not moved: the same regexes read 142 at
`c6643153` and 142 at `HEAD`, so this is not snapshot drift.

**The verdict 294 drew is unaffected** — at 139 or 142 the conclusion *"a token
file is where hex belongs"* is identical, and three more hex literals do not turn
a non-violation into one. This is the shape `ENVIRONMENT.md` already names:
*harmless in their conclusions and wrong in the audit trail a later wake re-runs*.

claim** — and the cost is exactly what that rule predicts: the next wake cannot
re-run it, only re-derive it, and re-deriving is where a second, different
mistake comes from.

## Filed, not built

**Should `check:selftests` EXECUTE each self-test rather than grepping for the
branch?** Measured before proposing: the base rate is **1 of 20**, and the three
gates that fooled this grill's own counter prove there is no single parseable
output shape — `selfTest()`'s `self-test: <name>` lines, `ok  <name>` lines, and
a bespoke one-line verdict all exist today. Executing them would mean either
standardising 20 gates onto one marker, or asserting only on exit code, which
cannot tell "ran 18 cases, all passed" from "ran none". That is a real design
question with a real cost, so it is **filed as 315.3**, not built inside a grill.
The narrow property this grill actually proved — *a self-test must not sit below
an early return* — is what 315.1 fixes, at the one site that has it.
