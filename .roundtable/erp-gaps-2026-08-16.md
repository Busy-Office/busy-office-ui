# ERP component gap research (2026-08-16)

Triaged from user ask: "after research anything to triage the docs or add to
components that may need for ERP." Researched dedicated enterprise/ERP
design systems (SAP Fiori, IBM Carbon, Ant Design/Pro, Salesforce Lightning)
rather than generic marketing-site frameworks — different comparison set
than the earlier docs-IA pass (Slice 16).

## Correction to the research

The research agent flagged "saved views / variant management" as a gap
(citing Fiori's Variant Management, Salesforce's list-view picker). **This
is already shipped** — `initSavedViews()` (`packages/core/src/js/behaviors/
saved-views.ts`), documented on `/components/filters`, used live in the
reporting-dashboard pattern. Verified against source before triaging, not
taken on faith.
