## 6. Round-table: is a CSS-first ERP framework the right bet, for whom, versus what?

This is a Hypothesis: the verdict has one source, the readings above.
- **ERP team lead:** yes, for a small team building server-rendered screens
  (htmx, Django, Rails) that needs dense grids without adopting a JS
  framework. The first user's classes all still resolve and its licence
  precondition has shipped, but it has not moved since 09-09.
- **Adoption skeptic:** there is no outside demand to point to: about 3
  downloads a day, 0 CDN hits on `dist/`, and 0 non-owner GitHub signals.
  Every comparator is 100x or more larger, and SAP already offers both a
  CSS route and a JS route.
- **Maintainer:** the defensible niche is one ~16 kB-gzip package with CSS,
  delegated behaviour and htmx together, for server-rendered ERP builders.
  For SAP-branded apps UI5 wins, and for React teams PatternFly or Carbon
  does.

Until one user who did not write it adopts it, "right bet" stays a
Hypothesis. That is an argument for M1's first-user conformance property
(O5), not for more machinery.
