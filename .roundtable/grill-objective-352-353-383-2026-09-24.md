## 1. 352.2 — the verdict stands on the other branch

- **F1 (high, Evidence): the flush-to-select-all ratio depends on the Chrome
  build.** The recorded Xeon (Chrome 141) read the flush at 24-38× select-all
  at every row count, not only at 20k, where the closure had explained it away
  as run-to-run spread. The verifier ran Chrome 141 on this same M4 and got
  28-31× across two sittings, against 14× on Chrome 153 interleaved. With the
  Chrome build held fixed, the two machines move both columns roughly
  together. So the two workloads do scale apart, and the cause is the browser
  build. That is the Accept's "legitimately scale apart" branch. The closure
  took a third, unlisted outcome (F7) and dismissed the Xeon.

  throttle is about 0.79 s on the M4 with the current stylesheet (0.72 s even
  with the August one).
- **F3 (medium): the published throttled rows cannot be a 4× throttle of the
  published unthrottled sitting.** They read about 1× the unthrottled rows.
  The closure's throttled ratios were derived from its unthrottled ones, so
  they were not independent confirmation.
- **F4, F5, F6, F8-F12 (low to medium).**

## 2. 352.1 — a stale dist got past it

- **F1 (medium, Evidence): a stale dist passed the check and still produced the
  false select-all failure.** Built before a behaviour existed, the install has
  every file the check lists, but `index.js` lacks an export that po-app's
  template imports. The module fails to link and select-all "fails". Found by
  deleting one export line; also reproduced through `measure:stress
  --no-install`.
- **F2 (low): two of the three red-proof observations could not fail.** "did
  not select 0 times" is not `check:po-app`'s text, and exit 1 happens either
  way. The transitive walk was never exercised.
- **F3 (low): the message said "not built" when only po-app's install was
  stale.**
- **F4 (low): an `/assets/` path written as a template string drops out of the
  check silently.**
- **Fixed:**

    `/assets/js/index.js` against the installed `index.js`'s exports.
  - It names the cause from what it can observe: `packages/core/dist` absent

    install; otherwise a partial or stale dist.
  - It refuses when `server.mjs` mentions `/assets/` more times than it has
    literal paths.
  - It strips comments before walking imports.
  - All five branches are red-proved on scratch copies (healthy, stale dist,
    stale install, not built, partial), plus the unparsable-reference refusal.
