## Defect A — Slice 345's own correction missed a third site, because the phrase wraps

`161ede68` — one commit — says **FOUR** in its subject, in Slice 345's heading
and in Slice 345's body, and **five** in the closing annotation it wrote on

```

```

`git log -L '/342.1 — DONE/,+2:ROADMAP.md'` attributes both spellings to that
one commit. The hand-off records the correction being made — *"the heading and
body both said 'five source lines' … Corrected before the commit"* — so two of
the three sites were found and the third was not.

**Five is wrong under both readings 345's own body supports.** Its table
decomposes the 41 as `14 + 10 + 10 + 4` from four source lines **plus three
one-off lines** on `/patterns/output-form`: four idiom lines, or seven lines
in total. The nearest true *five* in the slice counts **files** (its
NOT-VERIFIED block names five docs sources plus `app-launch.astro`'s sample;
the commit touches six), which is what makes this read as a conflation that
outlived the correction rather than a typo.

**Why the check that found the other two missed this one** — the phrase wraps
as `five source` / `lines`, so the obvious grep returns zero while the text is
plainly there:

```
git show 6d6f5af:ROADMAP.md > /tmp/r.md
python3 -c "import re; s=re.sub(r'\s+',' ',open('/tmp/r.md').read()); \
  print(s.count('five source lines'), s.count('FOUR source lines'))"   # 1 2
grep -c 'five source lines' /tmp/r.md    # 0   <- the miss
grep -c 'FOUR source lines' /tmp/r.md    # 2
```

**Read at `6d6f5af`, the parent of this commit, and no figure for *this* commit
is published — `327.2`'s effect fires here in its strongest form.** The
correction block, and the slice entry describing it, both contain the phrases
they count, so every attempt to state the current value changes it: `3 4`, then
`5 5`, then `6 5`, each stale before the edit that measured it had finished.
That is a regress, not three mistakes, and the way out is CLAUDE.md's own rule —
**name the property, not the value.** Whitespace-normalised sees every
occurrence; line-based misses exactly the wrapped one, which at `6d6f5af` is the
only one, so it sees 0 of 1. Re-run against a named revision, never the tree.

**This is `322.3`'s mechanism, one wake after Slice 343 refused a helper for

failure is in a different population it did not measure — **a wake's own

## This grill's own instruments — five were wrong on their first output, by THREE different mechanisms

The count and the split are both stated, because "all of them the same way"
was the first thing written here and it is false — only two are the wrap:

**Two by the wrap mechanism** — the finding's own mechanism turning up in the
tool used to find it, which is the strongest evidence the population `346.1`
names is real:

1. **The first search for the `five` / `FOUR` contradiction was a line-based
   `grep 'five source lines'` and returned nothing.** The defect was visible
   only because the slice text had been read whole, minutes earlier.
2. **The search for Defect B's claim — `grep -n "refusal and the command"` —
   also returned nothing**, the phrase being likewise wrapped
   (`… The refusal and` / `the command are in …`). The line to edit had to be
   located with a two-line sliding window.

**One by a token boundary.** The `docs-list` counts were wrong in *both* halves
on the first try: `\bdocs-list\b` matches inside `docs-list-bare`, because `-`
is a non-word character — the exact bug 322's own report names — and a plain
`grep -l 'docs-list-bare'` counts prose files too. A class-token matcher (split
every `class="…"` on whitespace, compare tokens) lands on 322's digits exactly.

**One by HTML entities** — the base-rate instrument of Defect B, above.

**And one that was not wrong so much as differently scoped, which is the case
FOR recording commands.** A hand-written re-derivation of Defect A's `1,433`
blast radius returned **11** slices where the published figure is 17, on a
narrower regex. Nothing adjudicated that; what settled it in one run was that
Slice 322 had *recorded its command*, and the recorded command returns the
published seventeen exactly. That is the counterfactual Defect B destroys:
where the command is written down, a disagreeing re-derivation costs a minute;
where it is not, it costs a re-derivation nobody can check.

Every one was caught by reconciling against a second, differently-shaped reading
before the number was used.
