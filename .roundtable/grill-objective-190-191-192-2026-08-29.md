## A. Rule 3 counts SLICES, not un-grilled slices, so it re-fires on material already grilled — **Evidence**

Slice **192 is itself an Objective grill**, and its window was `[186, 189, 190,
191]`. Two of the three slices rule 3 has just handed me — **190 and 191** — were
grilled hours ago, by me, in that slice.

So the honest scope of this grill is **192 alone**. Re-grilling 190 and 191
would produce exactly the "repeated subject" the `.roundtable/INDEX.md` check
exists to flag, and it would do so *while following the dispatcher correctly* —
which is the point. The counter advances on every closing slice, including the
grill slices, so a grill mechanically re-arms rule 3 with its own output.

**Counter-evidence, and it is why this is not proposed as a fix.** The overlap
is cheap to notice — the index check catches it in one read, as it just did —
and a rule that occasionally re-offers material is far safer than one that can
skip material. 176.3's window closed the same shape of question: an
always-true-ish predicate that costs little was left alone because the cost of
tightening it exceeded the cost of the overlap. **No rule change proposed.**
What is proposed is that a grill say which of its slices are already covered,
which this one does in its first line.

## B. Slice 192 asserted a number beside its measurement — the exact pattern it was written to document — **Evidence**

192's finding A is *"every defect in 173.2 was in something ASSERTED; the one
thing MEASURED was correct."* Its own report then quotes **"1 of 138 built
pages"** — a figure lifted from 190, carried forward without being re-run.

That is the same shape one level up, and it is not hypothetical: CLAUDE.md's
"number you report is load-bearing" section now records that a grill in this
same window *"asserted beside it that no enumeration of the built site returns
its stated 138"*. So **138 was disputed by one grill and repeated unverified by
another**, and the plainest possible walk settles it:

```
find apps/docs/dist -name 'index.html' | wc -l      # 138
```

138 is correct. **The repetition happened to be right, which is the least
useful way for it to end** — a wrong repeat gets caught, a right one teaches
nothing and licenses the habit.

**Counter-evidence**: 192 was written in the same hour as the CLAUDE.md
passage, so the two are near-simultaneous rather than one ignoring the other.
And a grill quoting the slice it grills is normally correct behaviour — the
defect is quoting *a measured figure* without re-running a command that takes
one second.
