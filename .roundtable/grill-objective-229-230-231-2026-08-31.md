## A. Slice 229 — the two findings

### A1 (→ 232.1) — the BROAD base rate excludes the past tense: 7, not 2

229.3 refuses a proposed `check:selftests` assertion. Its BROAD candidate is
*"`owes` within 120 chars of `--self-test` or `@heuristic`"*, and it reports the
base rate as **2, both false positives**. It publishes this to reproduce that:

```
grep -rniE 'owes?\b' apps/docs/scripts packages/core/scripts --include='check-*.mjs'
```

`owes?\b` is `owe` + optional `s` + a word boundary. It **cannot match the past
tense** — the boundary fails against the `d`:

```
printf 'this line used to say it was owed\n' | grep -cE 'owes?\b'      # 0
printf 'this line used to say it was owed\n' | grep -cE 'owe[sd]?\b'   # 1
```

Past tense is not an edge case here. **It is the wording 229.2's own fix used** —
all five corrected headers read *"the debt is PAID, and this line used to say it
was owed"*. Whole-word count:

```
grep -rlwE 'owes|owed' apps/docs/scripts packages/core/scripts \
  --include='check-*.mjs' | grep -v check-selftests.mjs | wc -l     # 7
```

**BROAD as 229.3 defines it fires on all five corrected files once the tense is
included.** The gap between `owed` and `--self-test` in `check-floor.mjs` is
**18 characters**, on adjacent lines — which is also why a line-based `grep`
reports nothing and a multiline test reports five:

```
node -e "const s=require('fs').readFileSync(process.argv[1],'utf8');
  console.log(/owed[\s\S]{0,120}--self-test|--self-test[\s\S]{0,120}owed/.test(s))" \
  apps/docs/scripts/check-floor.mjs      # true, and true for all five
```

So BROAD's complete false-positive set is **7, not 2**, and the five it gains are
exactly the set 229.3's own Accept names as the ones the assertion must not fire
on.

**The refusal is strengthened, not overturned.** 229.3's decisive argument is its
third injection row — a *reworded* stale claim leaves both predicates green — and
no base rate touches that. What the correction adds is a sharper reason: **a gate
reading prose about self-tests trips on the correction that fixed the thing it
exists to catch**, because explaining a paid debt requires naming the debt. That
is CLAUDE.md's *"verifying a removal: assert on structure, never on raw text"*,
recorded three times about a removal ASSERTION and here killing a proposed GATE.

**Widening the word is worse, and that was measured too.** `owe[sd]?\b`
unanchored returns **17** files, matching inside *allowed* (9), *windowed* (7),
*showed* (3), *followed*, *swallowed*, *overflowed*, *narrowest*, *slowest*,
*lowest*. Only `-w` gives the honest 7. 192.1's shape: the defect landed in what
shipped beside the carefully red-proved claim.
