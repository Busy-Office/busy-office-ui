## Findings acted on

1. **`check-page-shape.mjs` had never once run against `scan`.** Its
   `hasRules` filter required a `.bo-` selector, and `scan.css` is 100%
   `body[data-scan-result]::after` — zero `.bo-` selectors. 126.2 generalized
   exactly this definition in `extract-api.mjs`, `check-components-used.mjs`
   and `check-data-hooks.mjs`; this gate kept the old half of the rule. A
   skipped page is indistinguishable from a passing one, so nobody saw it —
   and `scan.astro` was missing `<DsaScore>` the whole time. Membership now
   comes from `api.json` (generated from the shipped artifact) instead of a
   regex. The gate went red on `scan` the instant it could see it, 39 → 40
   pages checked, and the DsaScore "not yet scored" branch — which roadmap
   94.5 recorded as unreachable by construction — now renders on a real page.

2. **The ORDER assertion shipped yesterday was a position heuristic inside a
   file tagged `@exact`.** CLAUDE.md's taxonomy names "a position" as the
   heuristic case outright, and this one's first draft *was* fooled
   (component-scoped, it false-positived on the composite `state-patterns`).
   Extracted as `demoAfterSpec()`, file retagged `@heuristic` with the reason
   that one heuristic check makes the file heuristic — the tag names the
   weakest link, not the average — and given a `--self-test` over four inputs
   including the composite shape that broke the draft. Red-proved by
   replacing the detector with `return false`: the self-test exits 1.

3. **A claim was shipping without a case and without a registered
   exemption.** file-upload's "on many phones `capture` REPLACES the file
   picker" is a mobile-OS behaviour headless Chromium cannot show. Keeping
   the sentence is right — it is *why* the page ships two inputs — but "there
   was no way to test it" must be a decision on the record, not an unwritten
   habit. `check-claims.mjs` now carries an EXEMPT list with this entry and
   the bar for joining it: unobservable in this harness for a stated reason,
   not merely awkward to reach.

4. **The column ladder had no stated ceiling.** Each tier costs a class AND a
   hand-picked breakpoint — one specific rule per tier, which is a slope. The
   CSS now states that three is the ceiling, why (must-have / useful /
   context, matching the cited floor), and that a fourth is a rethink into a
   numeric priority scale, never a `--quaternary`.

5. **`.demo-shell-frame` re-declared `.demo-frame`'s two lines** instead of
   composing on them — the compose-existing-primitives doctrine, unapplied to
   the docs' own stylesheet one day after that doctrine motivated the split.
   Now `class="demo-frame demo-shell-frame"` on all three sites, and the
   shell class carries only what a shell adds.
