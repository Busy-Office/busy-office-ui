## Counter-evidence, kept

This grill is itself evidence FOR the placement-rule discipline (192.1),
not just a confirmation of it: three prior grills in a row each found one
false or unreproducing claim, and the fear after three misses in a row is
that the next grill either forces a fourth miss to look useful, or stops
checking. Neither happened — the checks were run for real (each command
above was executed this pass, not copied from the source item), and the
answer was clean. A clean re-verification is exactly the outcome CLAUDE.md
names as "the least useful way for it to end" when it's a repeat of an
already-correct number (Slice 195's finding B) — but this is not a repeat of
an unverified number, it's an independent re-derivation of numbers that
were already pinned with their commands. The distinction is whether the
command was RUN this time, and it was.
